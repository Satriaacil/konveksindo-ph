# KONVEKSINDO.PH — Design System

## 1. Design Direction

Gaya visual website:

* Professional
* Modern
* Premium
* Clean
* Bold
* Trustworthy

Website harus terlihat profesional tanpa menggunakan terlalu banyak elemen dekoratif.

---

## 2. Brand Colors

Warna utama:

| Nama        | Warna | Penggunaan                    |
| ----------- | ----- | ----------------------------- |
| Primary Red | Red   | CTA, highlight, elemen utama  |
| Gold        | Gold  | Accent, highlight tertentu    |
| White       | White | Background dan ruang utama    |
| Black       | Black | Text, heading, elemen kontras |

### Aturan Penggunaan

Merah dan gold digunakan sebagai **accent**, bukan memenuhi seluruh halaman.

Putih digunakan sebagai warna background utama.

Hitam digunakan untuk teks dan elemen yang membutuhkan kontras.

---

## 3. Typography

Tipografi harus memiliki karakter:

* Modern
* Profesional
* Mudah dibaca

### Heading

Digunakan untuk:

* Hero title
* Section title
* Card title

### Body

Digunakan untuk:

* Deskripsi
* Informasi produk
* Informasi layanan
* Konten pendukung

Prioritas utama adalah readability pada desktop dan mobile.

---

## 4. Spacing

Gunakan sistem spacing yang konsisten.

Prinsip:

* Section memiliki ruang yang cukup
* Konten tidak terlalu rapat
* Jarak antar elemen mengikuti hierarchy
* Hindari penggunaan margin/padding secara acak

---

## 5. Buttons

### Primary Button

Digunakan untuk tindakan utama seperti:

**Hubungi Kami**

Karakter:

* Background primary red
* Text putih
* Kontras tinggi
* Mudah terlihat
* Memiliki hover state

### Secondary Button

Digunakan untuk tindakan pendukung.

Karakter:

* Lebih sederhana
* Tidak mengalahkan primary CTA

---

## 6. Cards

Card digunakan untuk:

* Produk
* Layanan
* Portfolio

Karakter:

* Clean
* Border radius konsisten
* Spacing internal cukup
* Gambar menjadi elemen utama
* Tidak menggunakan dekorasi berlebihan
