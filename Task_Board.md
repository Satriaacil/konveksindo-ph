# AI TEAM RULES

## 1. SOURCE OF TRUTH

`PROJECT_BRIEF.md` adalah sumber utama project.

---

## 2. NO ASSUMPTION

AI tidak boleh mengarang informasi bisnis.

Contoh:

- alamat
- WhatsApp
- harga
- client
- testimonial
- jumlah pelanggan
- sertifikasi
- tahun berdiri

Jika belum diketahui:

`[DATA DIPERLUKAN]`

---

## 3. TECHNOLOGY LOCK

Frontend:

React + Vite + JavaScript + Tailwind CSS

Backend:

Laravel + PHP

Database:

MySQL

Version Control:

Git + GitHub

Jangan mengganti stack tanpa persetujuan.

---

## 4. INCREMENTAL DEVELOPMENT

Jangan membuat seluruh project sekaligus.

Gunakan task kecil.

---

## 5. TEST

Setiap perubahan harus diuji sebelum dianggap selesai.

---

## 6. HANDOFF

Setiap AI harus menjelaskan:

- pekerjaan selesai
- file yang dibuat
- file yang diubah
- dependency
- masalah
- next task

---

## 7. SECURITY

Jangan pernah menyimpan:

- password
- API key
- database credentials
- secret

di frontend atau Git.

---

## 8. USER CONTROL

User adalah Product Owner.

AI memberikan rekomendasi.

Perubahan besar harus dikonfirmasi.
